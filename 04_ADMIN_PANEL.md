# Admin Panel — детальная UX-спека

Страницы, вайрфреймы, взаимодействия, роли.

---

## 0. Общие UX-правила

- **Layout:** сайдбар слева + топбар + контент.
- **Сайдбар:** сворачиваемый, иконки lucide-react, активный пункт подсвечен primary-цветом темы.
- **Топбар:** глобальный поиск (⌘K), переключатель языка, переключатель темы, нотификации-колокольчик, аватар с меню (profile, logout).
- **Адаптив:**
  - desktop ≥ 1280 → полный сайдбар.
  - tablet 768–1279 → свёрнутый сайдбар (иконки).
  - mobile < 768 → drawer сверху, bottom-nav для 4 основных пунктов.
- **Темы:** Minimal (monochrome, тёмный дефолт), Friendly (мягкий пастельный светлый дефолт), Premium (тёмный + золото). Владелец меняет в Settings. Дефолт — Friendly.
- **Tables:** TanStack Table, server-side pagination, sort, column picker, bulk actions.
- **Forms:** react-hook-form + zod, inline-ошибки, toast на успех.
- **Модалки** используем редко, предпочитаем боковые Drawer для CRUD (как в Notion/Linear).
- **Пустые состояния** (empty states) рисуются красиво: иллюстрация + CTA.
- **Skeleton loaders** вместо спиннеров на списках.
- **Hotkeys:** `⌘K` поиск, `g d` дашборд, `g c` клиенты, `g b` брони, `?` справка.

## 3. Bookings

### 3.1. Calendar view (по умолчанию)

- Неделя / День / Месяц (переключатель).
- Колонки = мастера (день и неделя), строки = время (с шагом 15 мин).
- Каждая бронь = цветной блок (цвет мастера), drag'n'drop для переноса.
- ЛКМ на пусто → модалка создания.
- ЛКМ на бронь → боковой drawer с деталями.
- Фильтры: мастер, услуга, статус.

### 3.2. Table view

- Колонки: дата/время, клиент, мастер, услуга, цена, статус, действия.
- Фильтры: период, мастер, услуга, статус, source (bot/admin).
- Bulk: отменить, экспортировать XLSX.

### 3.3. Boooking detail (drawer)

- Инфо: клиент (клик → карточка), мастер, услуга, цена, статус, метод оплаты.
- История изменений (audit).
- Кнопки: Изменить, Перенести, Отменить, Отметить как выполненное, no-show.

## 5. Masters

### 5.1. Список

Карточки-плитки: фото, имя, специализация, рейтинг ⭐, активных записей на сегодня, «редактировать».

### 5.2. Карточка мастера

Табы:
- **Профиль:** фото, имя для публики, био, специализация, цвет в календаре (color picker), sort_order.
- **Услуги:** чекбоксы — какие услуги делает + override цены/времени.
- **Расписание:** свой календарь, устанавливает working/vacation/break. Поддержка RRULE («каждый вт-чт 10-18 кроме последней недели месяца»).
- **Клиенты:** постоянные клиенты мастера.
- **Статистика:** выручка, кол-во, рейтинг, отзывы.
- **ЗП:** процент от выручки (задаётся owner), расчёт по периоду, экспорт.
- **Логин:** email/пароль (создаёт owner), переключатель активности.

## 8. Broadcasts

### 8.1. Список рассылок

Колонки: название, сегмент, статус (draft/scheduled/sent), получатели, sent/delivered, дата.

### 8.2. Редактор (пошагово, wizard)

**Шаг 1 — Сегмент:**
- Все
- Новые (N дней)
- Спящие (не были ≥ N дней)
- ДР на период
- Брали услугу X
- У мастера Y
- VIP (top %)
- Регулярные (≥ N раз)
- По тегу
- По языку
- No-show
- Кастомный: query builder (AND/OR условия)
- **Исключить:** блэклист, отписавшихся.

В превью справа — живой счётчик получателей.

**Шаг 2 — Контент:**
- Табы EN/RU/UK/BG.
- Поле текста, эмодзи-пикер, превью Telegram.
- Загрузка фото/видео.
- Inline-кнопки (текст + URL / callback).
- Кнопка «🌐 Перевести автоматически».

**Шаг 3 — Расписание:**
- Отправить сейчас
- Отправить в (datetime)
- Повторять (daily/weekly/monthly) — v1.1

**Шаг 4 — Preview и запуск:**
- Показать пример сообщения как в ТГ.
- Кнопка «🚀 Отправить» / «💾 Сохранить черновик».

**После отправки:**
- Live-прогресс-бар (sent/total).
- Метрики delivered/blocked/clicked.
- Детали ошибок.

## 10. AI

### 10.1. Knowledge Base

Двухпанельный интерфейс:
- Слева: список документов (drag'n'drop upload PDF/DOCX/TXT; кнопка «+ Новая запись»).
- Справа: текущий документ — редактор (markdown) + метаданные (язык, тип, source).
- Под редактором: «Чанков: 12 • Проиндексировано 2 мин назад».

### 10.2. Prompt

- Системный промпт (textarea с подсветкой переменных `{name}`, `{lang}`).
- Табы по языкам (4 шт).
- Few-shot примеры (CRUD).
- Температура (slider 0–1).
- Переключатели: AI_enabled, allow_booking (off v1), citations visible.
- Кнопка «Сохранить» → версионирование (можно откатиться).

### 10.3. Test chat

Эмулятор клиента: можно вбить вопрос и увидеть ответ + какие чанки процитированы (подсвечены).

### 10.4. Conversations

- Лента разговоров: дата, клиент, первая реплика, кол-во сообщений, есть ли flagged.
- Drill-down: полный диалог + цитируемые чанки.
- Фильтр «только плохие ответы».

## 11. Blacklist

- Таблица: имя, телефон, ТГ, причина, добавил, дата, срок (nullable).
- Действия: «Убрать из блэклиста» / «Продлить» / «Изменить причину».
- Кнопка «+ Добавить» — диалог поиска клиента + причина + срок.
- Клиенты могут попасть авто: N no-show подряд (настраивается в Settings).

## 13. Settings (only owner)

Табы слева:

### 13.1. Brand

- Название салона, описание (4 языка).
- Логотип (drop image, 256×256).
- Cover image (1200×400).
- Favicon.
- Primary color (picker).
- Тема: Minimal / Friendly / Premium.
- Контакты: телефон, email, адрес, карта-link, соцсети.

### 13.2. Localization

- Валюта: EUR / USD / UAH.
- Часовой пояс (select).
- Язык по умолчанию (EN/RU/UK/BG).
- Формат даты, времени.

### 13.3. Working hours

Сетка 7 дней × (open / close / break from-to). Ещё блок «Выходные даты» (календарь).

### 13.4. Cancellation policy

- Бесплатная отмена за: [24] часов.
- Политика при поздней отмене:
  - ⬜ Запретить отмену (писать «позвоните»)
  - ✅ Штраф: [ 10 € ] применять к следующей записи
  - ⬜ Автоблэклист после [3] no-show
- Правила текст (для бота, 4 языка).

### 13.5. Prepayment

- Включена ON/OFF.
- Процент (по умолч. 20%).
- Минимум (по умолч. 5 €).
- Не требовать для постоянных клиентов (≥ N визитов).

### 13.6. Reminders

- Интервалы чекбоксы: ✅ 24ч ✅ 2ч ✅ 30мин (кастомно добавить).
- Текст для каждого (4 языка).

### 13.7. Payments

- Провайдер: Telegram Payments / Stripe / LiqPay / ePay.bg.
- Provider token / API keys.
- Тест-режим.
- Автовозврат при отмене (checkbox).

### 13.8. Telegram

- Bot token (write-only, показывается ****token).
- Webhook URL (read).
- Bot username.
- Admin notify chat id (для нотификаций).
- Кнопка «Проверить подключение» → `getMe` + `getWebhookInfo`.

### 13.9. SMTP

- Host, port, user, pass, from_name.
- Тестовое письмо.

### 13.10. Backups

- Расписание (ежедневно HH:MM).
- Ротация (7/4/3).
- Кнопка «Скачать последний».
- Кнопка «Создать сейчас».

### 13.11. License

- License key (showed).
- Покупка/дата.
- Версия платформы.
- Ссылка «Проверить обновления».

## 15. Мастерская панель (Master role)

Упрощённая навигация:

- **Мой день** — расписание на сегодня + быстрая карточка клиента.
- **Моё расписание** — свой календарь, можно ставить working/vacation/break.
- **Мои клиенты** — только те, кто когда-либо был у меня.
- **Мои записи** — таблица.
- **Моя статистика** — выручка, кол-во, рейтинг, отзывы.
- **Мой профиль** — фото, био, специализация.

**Что мастер не видит:** других мастеров, финансы салона, рассылки, AI, блэклист, настройки, сотрудники.

## 16. Ресепшен (Reception role)

## 18. Темизация

`theme/*.ts` экспортирует объект CSS-variables:

```ts
export const friendlyTheme = {
  '--bg': '#FAF7F5',
  '--fg': '#2A241F',
  '--primary': '#D97757',
  '--primary-fg': '#fff',
  '--card': '#fff',
  '--border': '#ECE4DF',
  '--muted': '#F5EEEA',
  '--accent': '#F4DED0',
  '--radius': '14px',
  '--font': '"Inter", sans-serif',
}
```

При переключении темы в Settings — обновляются CSS vars через `document.documentElement.style.setProperty(...)` без перезагрузки.
