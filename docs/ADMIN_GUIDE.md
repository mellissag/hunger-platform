## 1. Первый вход и смена пароля

1. Откройте `https://your-domain/login`
2. Логин: `owner@adm-test.tech`, пароль из вывода install.sh

**Сразу после входа:**

- Settings → Сотрудники → выберите Owner → «Редактировать» → смените email и пароль
- То же для остальных тестовых аккаунтов или удалите неиспользуемые

---

## 2. Дашборд

Главная страница после входа. Показывает:

- **KPI блок**: выручка за сегодня/неделю/месяц, количество записей, новые клиенты
- **График**: записи по дням (14 дней назад и 14 вперёд)
- **Топ-мастер**: лидер по выручке за месяц
- **Последние события**: последние 10 записей, отмен, отзывов
- **Бот-статистика**: посещения сегодня, новые пользователи

## 3. Услуги и категории

### Создание категории

1. Services → «+ Категория»
2. Название на 4 языках (EN/RU/UK/BG)
3. Иконка (emoji или загрузка)
4. Порядок сортировки (drag'n'drop в списке)

### Создание услуги

1. Services → «+ Услуга»
2. Заполнить поля:
   - Название на 4 языках (кнопка «Автоперевод» — черновик через Gemini)
   - Описание на 4 языках
   - Категория
   - Цена и длительность (в минутах)
   - Фото (рекомендуется 800×600px, до 2 MB)
   - Мастера, выполняющие услугу (можно задать цену/длительность per-master)

### Видимость услуги в боте

Тогл «Видна в боте» на карточке услуги. Изменение применяется **мгновенно** (через Redis Pub/Sub) — бот перестаёт показывать услугу без перезапуска.

### Удаление услуги

Услугу нельзя удалить, пока есть **активные (confirmed) записи** на неё. Сначала отмените или завершите записи.

## 4. Мастера

### Создание мастера

1. Masters → «+ Мастер»
2. Заполнить: имя, фото, специализация, описание (на 4 языках), цвет в календаре
3. Привязать услуги: вкладка «Услуги» → выбрать из списка
4. Создать аккаунт (опционально): вкладка «Аккаунт» → «Создать логин»

### Расписание мастера

Masters → [имя мастера] → «Расписание»:
- Добавить рабочие дни/часы
- Добавить выходные, больничные, отпуск, блоки времени
- Поддерживается повторение (еженедельно)

### Деактивация мастера

Тогл «Активен». Неактивный мастер не отображается в боте при выборе мастера.

## 5. Клиенты и заметки

### Список клиентов

- Фильтры: по имени, телефону, тегам, дате последнего визита
- Теги: добавляются в карточке клиента
- Экспорт в CSV

### Карточка клиента

| Блок | Содержимое |
|---|---|
| Шапка | Фото (из TG), имя, телефон, @username, ДР, язык, теги, флаг блэклиста |
| KPI | Всего записей, выручка, no-show, последний визит |
| Заметки | Свободные записки с датой и автором |
| История записей | Таблица с фильтром по статусу |
| Отзывы | Оценки и комментарии |

### Заметки (важно!)

Заметки — «записки» о клиенте:
- «Любит кофе без сахара перед процедурой»
- «Аллергия на хлоргексидин»
- «Постоянный клиент — давать скидку 10%»

**Добавление заметки:**
1. Карточка клиента → «+ Заметка»
2. Написать текст
3. Можно закрепить (Pinned) — появится вверху списка

**Кто может редактировать:**
- Owner и Admin — все заметки
- Master — только свои
- Reception — все заметки

## 6. Бронирования

### Просмотр

Bookings → два режима:
- **Таблица**: список с фильтрами (по дате, мастеру, услуге, статусу)
- **Календарь**: сетка по мастерам на день/неделю

### Создание брони вручную

1. Bookings → «+ Запись» (или клик на слот в календаре)
2. Выбрать: клиент → услуга → мастер → дата/время
3. Статус `confirmed` устанавливается автоматически

Если клиента нет в базе — создайте нового: имя и опционально телефон.

### Статусы броней

| Статус | Описание |
|---|---|
| `pending` | Ожидает подтверждения |
| `confirmed` | Подтверждена |
| `completed` | Завершена (мастер отметил) |
| `cancelled_by_client` | Клиент отменил через бот |
| `cancelled_by_salon` | Отменена администрацией |
| `no_show` | Клиент не пришёл |

### Отметить No-Show

Bookings → запись → «No-Show». Счётчик no-show клиента увеличивается. При достижении порога — автоматически попадает в чёрный список (зависит от настройки политики отмен).

## 7. Расписание

Schedule → общий календарь всех мастеров.

- **Drag'n'drop**: перетащить запись на другой слот
- **Цвета**: каждый мастер имеет свой цвет (задаётся в карточке мастера)
- **Фильтр по мастеру**: вверху страницы
- **Добавить блок**: клик на пустой слот → «Блок» (перерыв, выходной)

## 8. Рассылки

### Создание рассылки

1. Broadcasts → «+ Рассылка»
2. Выбрать сегмент (кому отправить):

| Сегмент | Описание |
|---|---|
| Все клиенты | Весь список |
| Новые (N дней) | Зарегистрировались за последние N дней |
| Не приходили | Не посещали более N дней |
| ДР на этой неделе/месяце | День рождения скоро |
| Брали услугу X | По конкретной услуге |
| Были у мастера Y | По конкретному мастеру |
| VIP | Топ-N% по выручке |
| По тегам | По кастомным тегам клиентов |
| No-show | Клиенты с записями no-show |

3. Написать текст (поддерживается форматирование Markdown Telegram)
4. Можно добавить медиафайл (фото/видео)
5. «Автоперевод» — черновик на 4 языках через Gemini (клиент получает на своём языке)
6. Запланировать или отправить немедленно

### Метрики рассылки

После отправки: sent / delivered / blocked / failed — в карточке рассылки.

**Лимит**: 30 сообщений/сек (встроенный rate limiter).

## 9. Статистика

Statistics → несколько вкладок:

### Бот
- Уникальных посетителей (день/неделя/месяц)
- Новых подписчиков (`/start`)
- Конверсия «посетил → записался»
- Брошенные воронки записи (%)
- AI-сессий

### Бронирования
- Всего, по статусам, средний чек, LTV
- Heatmap по часам и дням недели
- Retention (повторные визиты 30/60/90 дней)

### Мастера
- По каждому: выручка, записи, рейтинг, загрузка, топ-услуга
- Сравнение мастеров

### Услуги
- Топ по выручке и количеству
- «Мёртвые» услуги (0 записей за 30 дней)

### Финансы
- График выручки по периодам
- Прогноз (линейный)
- Зарплаты мастеров (по % ставке из настроек)
- Экспорт в XLSX/PDF

## 10. AI-консультант

### База знаний

AI → База знаний:
- Загрузить документ (PDF, DOCX, TXT) или ввести URL
- Написать текстовую запись вручную
- Документ автоматически разбивается на чанки и индексируется (pgvector)

Рекомендуемые документы:
- Прайс-лист
- FAQ (часто задаваемые вопросы)
- Правила салона (отмена, предоплата)
- Описание каждой услуги
- О мастерах

### Системный промпт

AI → Промпт → редактировать системный промпт. Переменные: `{salon.name}`, `{user.lang}`, `{kb_chunks}`.

### Тестирование

AI → База знаний → «Тест-чат» справа: задайте вопрос как клиент — увидите ответ и процитированные чанки.

### Настройки AI

| Параметр | Описание |
|---|---|
| Включить AI | Показывать кнопку «Консультант AI» в боте |
| Разрешить AI записывать | Запрещено по умолчанию (v1) |
| Температура | 0.0–1.0 (выше = более творческий) |
| Модель | gemini-1.5-flash (по умолчанию) |

## 11. Чёрный список

Blacklist → список клиентов с запретом записи.

**Добавить вручную:**
1. Clients → карточка клиента → «В чёрный список»
2. Или Blacklist → «+ Добавить»
3. Указать причину и опциональную дату истечения

**Автоматически** (зависит от настройки):
- При превышении числа no-show
- При нарушении политики отмен

Клиент в чёрном списке получает сообщение при попытке записаться через бот.

## 12. Настройки (Owner only)

Settings → несколько разделов:

### Бренд
- Название салона, описание, логотип, обложка
- Контакты, адрес, соцсети
- Тема (Minimal / Friendly / Premium)
- Основной цвет (color picker)
- Favicon

### Бронирования
- **Отмена**: бесплатно за N часов
- **Политика после срока**: ничего / штраф / чёрный список
- **Размер штрафа**
- **Мин. время до записи**: сколько часов вперёд можно записаться
- **Буфер**: пауза между записями (минуты)

### Напоминания
- Интервалы (по умолчанию: 24ч, 2ч, 30 мин)
- Через сколько часов после записи просить отзыв

### Предоплата
- Включить/выключить
- Процент предоплаты
- Провайдер: Telegram Payments, Stripe, LiqPay, ePay.bg

### Telegram
- Токен бота
- Webhook URL (читать)
- Кнопка «Переустановить webhook»

### SMTP (опционально)
Для отправки приглашений сотрудникам по email.

## 13. Сотрудники (Owner only)

Settings → Сотрудники:

| Роль | Что может |
|---|---|
| Owner | Всё, включая настройки и управление сотрудниками |
| Admin | Всё кроме настроек и сотрудников |
| Master | Только свои данные |
| Reception | Клиенты, брони, расписание (только просмотр) |

**Создание аккаунта:**
1. «+ Сотрудник»
2. Указать роль, имя, email, пароль
3. Для роли Master — привязать к профилю мастера

**Сброс пароля:**
Список сотрудников → «Сбросить пароль» → новый пароль высылается на email (если настроен SMTP) или показывается на экране.

## 14. Бэкапы

Settings → Бэкапы:
- Кнопка «Создать бэкап сейчас»
- Список последних бэкапов с возможностью скачать
- Расписание автоматических бэкапов

**Ручной бэкап через SSH:**
```bash
bash /opt/hunger-platform/deploy/scripts/backup.sh
```

**Расположение бэкапов:**
```
/opt/hunger-platform/backups/
├── daily/    — 7 последних ежедневных
├── weekly/   — 4 еженедельных
└── monthly/  — 3 ежемесячных
```
