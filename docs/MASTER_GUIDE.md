## 1. Вход в панель

1. Откройте `https://your-domain/login`
2. Введите email и пароль, которые выдал администратор
3. После входа вы попадёте на дашборд мастера

**Если забыли пароль** — обратитесь к администратору (Settings → Сотрудники → Сбросить пароль).

---

## 2. Мой дашборд

Главная страница после входа:

| Блок | Описание |
|---|---|
| Сегодня | Список записей на сегодня с временем и именами клиентов |
| Ближайшая неделя | График записей на 7 дней |
| Моя выручка | За сегодня / неделю / месяц |
| Мои KPI | Количество записей, средний рейтинг, % отмен |

**Быстрые действия:**
- Клик на запись → откроется карточка клиента
- «Отметить выполненной» → запись переводится в статус `completed`

## 3. Моё расписание

Schedule → только ваше расписание.

### Просмотр

- **День**: все записи и блоки на конкретный день
- **Неделя**: сетка на 7 дней

### Добавить выходной / блок

1. Schedule → «+ Блок» (или клик на пустой слот)
2. Выбрать тип:
   - **Рабочее время** — добавить рабочий день/часы
   - **Выходной** — нерабочий день
   - **Перерыв** — блокировка слота (обед, личные дела)
   - **Отпуск** — длительная блокировка
   - **Больничный**
3. Указать дату/время
4. Можно включить повторение (еженедельно)

**Важно:** новые клиентские записи не создаются на заблокированные слоты автоматически.

### Перенос записи

Администратор может перенести запись на другое время. Мастер получит уведомление в Telegram.

## 4. Мои записи

Bookings → только ваши записи.

### Фильтры

- По дате (сегодня, эта неделя, произвольный диапазон)
- По статусу (confirmed, completed, cancelled, no-show)
- По услуге

### Действия с записью

| Действие | Когда использовать |
|---|---|
| Отметить выполненной | Клиент пришёл, услуга оказана |
| No-Show | Клиент не пришёл без предупреждения |
| Просмотр клиента | Открыть карточку клиента |

### Создание брони вручную

Bookings → «+ Запись» (только в своё расписание):
1. Найти или создать клиента
2. Выбрать услугу
3. Дата и время (из свободных слотов)

## 5. Мои клиенты и заметки

Clients → ваши постоянные клиенты (те, кто хотя бы раз был у вас).

### Карточка клиента

| Блок | Описание |
|---|---|
| Шапка | Имя, телефон, Telegram, ДР, теги |
| KPI | Посещений у вас, выручка, последний визит |
| Заметки | Записки о клиенте |
| История | Записи к вам |
| Отзывы | Оценки после ваших услуг |

### Заметки — как использовать

Заметки помогают персонализировать сервис. Пример заметок:

```
📌 Аллергия на парабены. Использовать только органику.
   — Добавила Анна, 15 янв 2026

Предпочитает запись во вторник утром.
   — Добавила Анна, 3 фев 2026

Именинница 12 апреля — поздравить при встрече.
   — Добавила Анна, 1 апр 2026
```

**Добавление заметки:**
1. Карточка клиента → «+ Заметка»
2. Введите текст
3. Для важных — нажмите «Закрепить» (появится вверху)

**Редактирование:**
Вы можете редактировать только свои заметки. Чужие — только читать.

## 6. Моя статистика

Statistics → только ваши данные.

### Доступные метрики

| Метрика | Описание |
|---|---|
| Выручка | За период (день/неделя/месяц/год) |
| Количество записей | По статусам |
| Средний рейтинг | На основе отзывов |
| Топ-услуга | Самая востребованная у вас |
| Загрузка | % занятых слотов от рабочего времени |
| Постоянные клиенты | Вернулись 2+ раза |

### Мои отзывы

Список отзывов с оценками и комментариями клиентов. Отзывы анонимны для мастера (имя клиента скрыто), только текст и оценка.

## 7. Мой профиль

Profile → ваша публичная страница (видна клиентам в боте).

### Что можно изменить

| Поле | Описание |
|---|---|
| Фото | Аватар, который видят клиенты в боте |
| Имя (display name) | Как вас видят клиенты |
| Специализация | Краткое описание (на 4 языках) |
| Bio | Подробное описание, опыт (на 4 языках) |

**Что нельзя изменить самостоятельно:**
- Список ваших услуг — настраивает администратор
- Цены — устанавливает администратор (с возможностью переопределения per-master)

## 8. Частые вопросы

### Клиент хочет записаться напрямую — что делать?

Создайте запись вручную: Bookings → «+ Запись».

### Клиент отменил запись — что произошло?

Запись автоматически переходит в статус `cancelled_by_client`. Если это было за пределами бесплатного периода отмены — администратор может применить штраф.

### Не могу войти в панель

Обратитесь к администратору для сброса пароля.

### Хочу изменить рабочие часы

Schedule → «+ Блок» → Рабочее время. Или попросите администратора изменить расписание.

### Клиент не пришёл — как отметить?

Bookings → найдите запись → «No-Show». Система зафиксирует это в профиле клиента.

### Как отправить клиенту сообщение?

Clients → карточка клиента → «Написать в Telegram» (открывает чат через бот).

### Я вижу записи другого мастера

Это ошибка — обратитесь к администратору. Мастер должен видеть только свои записи.
