# Roadmap — план релизов

Ориентир сроков рассчитан на одного разработчика + активного Cursor. При команде 2 человек — умножай скорость на ~1.7.

---

## 🚀 MVP (v0.9) — 2–3 недели

**Цель:** продаваемая демка — можно показать салону и сказать «берём».

### Неделя 1

- **Day 1–2.** Phase 0 + Phase 1: scaffolding + модели + миграции + seed.
- **Day 3.** Phase 2: auth + RBAC.
- **Day 4–5.** Phase 3: CRUD clients/masters/services.
- **Day 6–7.** Phase 4: booking engine + schedule (самое сложное — race conditions).

### Неделя 2

- **Day 8–10.** Phase 5: бот с core flows (язык → меню → запись → мои записи → отмена).
- **Day 11.** Phase 6: напоминания (reminders worker).
- **Day 12–13.** Phase 8 + 9 core: frontend скелет + login + dashboard + clients + masters + services + bookings.
- **Day 14.** Phase 14 (partial): docker-compose, install.sh, базовый деплой.

### Неделя 3 (опциональная полировка до показа)

- Phase 10: рассылки (3 основных сегмента).
- Phase 11: базовая статистика.
- Документация для демо.
- Seed выразительных демо-данных.

**Критерий готовности:** салон может зайти в админку, увидеть демо-данные, протестировать запись через бот, получить напоминание, отменить. Всё на 4 языках, на одной из 3 тем.

## 🏁 v1.0 — 4–5 недель от старта

Добавить к MVP:

- Phase 7: полноценный AI (RAG + Gemini + админ-управление).
- Phase 10 полный: все сегменты + расписание рассылок + метрики.
- Phase 11 полный: финансы, ЗП, экспорт XLSX/PDF.
- Phase 12: AI-админка, blacklist, settings (все табы), users, audit log.
- Phase 13: Mini App + review flow + admin notify.
- Phase 14: install.sh финальный, backup/update scripts, CI/release.
- Phase 15: тесты, a11y, lighthouse, changelog.

**Критерий:** пройдён чеклист из §15 `01_MASTER_SPEC.md`.

## 🎯 v1.1 — после первых продаж

Обратная связь с реальных салонов обычно даёт эти пункты:

- **Программа лояльности:** бонусы за визиты, рефералка «приведи друга», промокоды.
- **Повторяющиеся рассылки** (еженедельные/ежемесячные).
- **Напоминание о следующем визите** («вы не были у нас 60 дней — время освежить стрижку?»).
- **Интеграция с Google Calendar / Apple Calendar** через .ics + подписки.
- **SMS-напоминания** как дубль Telegram (Twilio/Vonage).
- **Мультивалютные тарифы** (например салон в Болгарии берёт и BGN и EUR — нет, просто EUR, но возможно конвертация для отчётов).
- **2FA TOTP** для owner.
- **Темы: кастомные пресеты** (импорт/экспорт темы).
- **Client self-service:** клиент видит свою историю в Mini App, может скачать инвойс.
- **Waitlist:** если слот занят — «поставить в лист ожидания, оповещу когда освободится».
- **Sticker packs для бота** для брендинга.

## 🌱 v1.2 — расширение

- **Публичная веб-страница салона** (отдельный роут `/public/*`) для SEO + онлайн-запись из Google.
- **Интеграция с онлайн-кассами** (ФЗ-54 если выход на РФ, или аналоги в EU).
- **Inventory / склад** — расходники, уведомления о низких остатках.
- **Multi-location** (несколько адресов одного салона) — аккуратно: всё ещё single-tenant.
- **Gift cards / сертификаты** — продажа и активация.
- **Packages / абонементы** — 10 визитов со скидкой.
- **API для партнёров** (beauty-агрегаторы).

---

## 🔮 v2.0 — новое поколение

Крупные архитектурные изменения:

- **Multi-tenant SaaS-опция** (для тех, кто не хочет свой VPS) с шардингом по salon_id.
- **Переход на event sourcing** для броней (full history + восстановление).
- **Fine-tuned модель** под конкретный салон (если кто-то захочет).
- **AI-автозапись:** бот сам подбирает слот и бронирует (с подтверждением клиента).
- **Video-консультации** через бот.
- **AR-примерка** в Mini App (макияж/причёска).

## Метрики успеха по фазам

| Версия | KPI |
|---|---|
| MVP | 1–2 пилотных салона за месяц |
| v1.0 | 10 продаж; средний цикл «интерес → покупка» < 2 недель |
| v1.1 | NPS клиентов-салонов ≥ 40; retention 80% за 6 мес |
| v1.2 | MRR-analog (повторные продажи / поддержка): 30% выручки |
| v2.0 | SaaS опция: 50+ арендаторов |

## Что делаем параллельно с разработкой

- **Маркетинг-сайт** (отдельный простенький сайт-лендинг для продажи).
- **Demo-инсталляция** на собственном VPS с демо-ключами — показывать клиентам по ссылке.
- **Видео-демо** (Loom 3–5 минут) — то, что смотрят все, кто не хочет живое демо.
- **Шаблоны писем** для первого контакта с салонами.
- **Онбординг-чеклист** для нового клиента-салона (как развернуть за 30 минут).
