# Hunger Beauty Platform — документация шаблона

> Универсальный шаблон для салонов красоты: Telegram-бот + Mini App + веб-админка + AI-консультант.
> Модель продажи — **одноразовая лицензия**, single-tenant (1 инсталляция = 1 салон).
> Стек: Python 3.12 + FastAPI + aiogram 3 · Next.js 14 + shadcn/ui · PostgreSQL 16 + Redis 7 · Gemini 1.5 Flash · Docker Compose.

---

## 💡 Важные архитектурные принципы

1. **Single-tenant.** Это упрощает код на порядок. Никогда не добавляй `salon_id` в WHERE.
2. **Всё управление из админки.** Никаких внешних админ-тулов — клиент не должен лезть в БД.
3. **4 языка синхронно.** i18n-чекер в CI не даст задеплоиться если не все переведено.
4. **Темы через CSS variables.** Переключение без перезагрузки страницы.
5. **Роль master ≠ user.** У мастера публичный профиль + опциональный логин.
6. **AI через адаптер.** Сегодня Gemini, завтра GPT, послезавтра локальный — меняется один файл.
7. **Бот и API — один процесс.** Webhook на FastAPI, общая БД, общий Redis.
8. **Worker отдельно.** ARQ обрабатывает напоминания, рассылки, индексацию — ни один RPS из бота не блокируется.
9. **Audit log везде.** Любой критичный эндпоинт пишет событие.
10. **Тесты для race conditions.** Бронирование в один слот — один победитель, остальные `SlotTakenError`.
