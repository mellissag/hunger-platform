## STEP 2 — Бэкенд: новые таблицы

Создай Alembic-миграцию:

### Таблица `expenses`
Ручные расходы салона.

Поля:
- `id` — UUID, PK
- `category` — enum: `rent` / `utilities` / `supplies` / `advertising` / `equipment` / `taxes` / `software` / `training` / `salary_bonus` / `other`
- `amount` — decimal (сумма в евро)
- `description` — string (описание, например «Аренда за май 2026»)
- `date` — date (дата расхода)
- `created_by` — FK на users (кто добавил)
- `created_at` — timestamp

### Таблица `salary_settings`
Настройки расчёта зарплаты для каждого специалиста.

Поля:
- `id` — UUID, PK
- `master_id` — FK на masters (уникальный — одни настройки на мастера)
- `salary_type` — enum: `percent` / `fixed` / `mixed`
  - `percent` — % от выручки которую принёс мастер
  - `fixed` — фиксированный оклад в месяц
  - `mixed` — базовый оклад + % если выручка превышает норму
- `percent_value` — decimal (например 40.0 = 40%). Используется для `percent` и `mixed`
- `fixed_amount` — decimal (оклад в евро). Используется для `fixed` и `mixed`
- `monthly_norm` — decimal (норма выручки в евро для `mixed` — если выручка ниже нормы, платится только оклад; если выше — оклад + % от суммы превышения)
- `updated_at` — timestamp

### Таблица `salary_payments`
История выплат зарплат.

Поля:
- `id` — UUID, PK
- `master_id` — FK на masters
- `period_start` — date (начало периода, например 2026-05-01)
- `period_end` — date (конец периода, например 2026-05-31)
- `revenue_amount` — decimal (выручка мастера за период)
- `calculated_amount` — decimal (рассчитанная зарплата)
- `paid_amount` — decimal (фактически выплачено)
- `status` — enum: `calculated` / `paid`
- `note` — string (опционально)
- `paid_at` — timestamp (nullable)
- `created_by` — FK на users
- `created_at` — timestamp

### Изменения в таблице `masters`
Добавить поле `reports_access` — boolean, default false. Если true — master с ролью admin видит раздел Отчёты.

## STEP 3 — Бэкенд: API эндпоинты

Все эндпоинты требуют роль `owner` или (`admin` + `reports_access = true`).

### P&L

`GET /api/v1/reports/pnl?period_start=2026-05-01&period_end=2026-05-31`

Возвращает:
```json
{
  "period": { "start": "2026-05-01", "end": "2026-05-31" },
  "revenue": {
    "services": 8500.00,
    "products": 320.00,
    "total": 8820.00
  },
  "expenses": {
    "salaries": 3200.00,
    "rent": 1200.00,
    "utilities": 180.00,
    "supplies": 450.00,
    "advertising": 200.00,
    "equipment": 0.00,
    "taxes": 350.00,
    "software": 50.00,
    "training": 0.00,
    "other": 120.00,
    "total": 5750.00
  },
  "gross_profit": 3070.00,
  "profit_margin_percent": 34.8,
  "prev_period_profit": 2800.00,
  "growth_percent": 9.6
}
```

Расчёт:
- `revenue.services` — сумма всех `bookings` со статусом `completed` за период (поле `price`)
- `revenue.products` — из таблицы продаж товаров (если есть)
- `expenses.salaries` — сумма `salary_payments.calculated_amount` за период
- `expenses.rent/utilities/etc` — из таблицы `expenses` по категориям
- `expenses.supplies` — из закупок склада за период

### Касса

В таблицу `bookings` добавить поле `payment_method` — enum: `cash` / `card` / `mixed` / `unpaid`. Default: `unpaid`. Устанавливается администратором при закрытии записи или в карточке бронирования.

`GET /api/v1/reports/cash?period_start=...&period_end=...&payment_method=all|cash|card`

Возвращает список всех финансовых операций по дням с разбивкой по способу оплаты:
```json
{
  "summary": {
    "total_income": 8820.00,
    "income_cash": 3240.00,
    "income_card": 5580.00,
    "total_expenses": 5750.00,
    "balance": 3070.00
  },
  "by_day": [
    {
      "date": "2026-05-27",
      "income": 650.00,
      "income_cash": 200.00,
      "income_card": 450.00,
      "expenses": 1200.00,
      "balance": -550.00,
      "transactions": [
        {
          "type": "income",
          "source": "booking",
          "amount": 650.00,
          "cash": 200.00,
          "card": 450.00,
          "description": "15 записей (наличные: €200, карта: €450)"
        },
        { "type": "expense", "source": "rent", "amount": 1200.00, "description": "Аренда за май" }
      ]
    }
  ]
}
```

### Зарплаты

`GET /api/v1/reports/salaries?period_start=...&period_end=...`

Возвращает расчёт зарплат по каждому мастеру:
```json
{
  "period": { "start": "2026-05-01", "end": "2026-05-31" },
  "masters": [
    {
      "master_id": "uuid",
      "name": "Анна",
      "salary_type": "percent",
      "revenue": 4200.00,
      "bookings_count": 38,
      "calculated_salary": 1680.00,
      "paid": false,
      "payment_id": null
    }
  ],
  "total_calculated": 3200.00,
  "total_paid": 1680.00
}
```

`POST /api/v1/reports/salaries/mark-paid` — отметить зарплату как выплаченную.
Тело: `{ master_id, period_start, period_end, paid_amount, note }`

`GET /api/v1/reports/salaries/{master_id}/history` — история выплат мастеру

### Настройки зарплаты мастера

`GET /api/v1/admin/masters/{id}/salary-settings` — получить настройки  
`PUT /api/v1/admin/masters/{id}/salary-settings` — сохранить настройки

### Расходы

`GET /api/v1/reports/expenses?period_start=...&period_end=...` — список расходов с фильтрами  
`POST /api/v1/reports/expenses` — добавить расход  
`PUT /api/v1/reports/expenses/{id}` — изменить  
`DELETE /api/v1/reports/expenses/{id}` — удалить

### Экспорт

`GET /api/v1/reports/export/pnl?period_start=...&period_end=...&format=xlsx` — экспорт P&L  
`GET /api/v1/reports/export/salaries?period_start=...&period_end=...&format=pdf` — расчётные листы  
`GET /api/v1/reports/export/cash?period_start=...&period_end=...&format=xlsx` — кассовый отчёт

Для генерации Excel использовать `openpyxl`. Для PDF использовать `weasyprint` или `reportlab`.

### Доступ для администратора

`PUT /api/v1/admin/masters/{id}/reports-access` — включить/выключить доступ к отчётам.
Тело: `{ reports_access: true/false }`. Только для роли `owner`.

На странице `/masters/{id}` (карточка специалиста) добавить раздел «Зарплата»:

- Поля в зависимости от типа:
  - `percent` → поле «% от выручки» (например 40%)
  - `fixed` → поле «Оклад в месяц» (€)
  - `mixed` → поле «Базовый оклад» (€) + «Норма выручки» (€) + «% сверх нормы» (%)

Подсказка под формой — расчёт в реальном времени:
- `percent`: «При выручке €4 200 зарплата составит €1 680»
- `fixed`: «Фиксированно €1 500 в месяц»
- `mixed`: «Оклад €800 + если выручка > €3 000, то +40% от превышения»

```
Емилия       Оклад €800       €2 100     19        €800        ⚠ Не выплачено
Елеонора     Оклад+%          €3 100     28        €720        ⚠ Не выплачено
```

- Строка со статусом «Не выплачено» — фон слегка жёлтый
- Строка со статусом «Выплачено» — галочка зелёная

**Кнопки на каждой строке:**
- «Детали» — раскрывает список записей мастера за период (дата, услуга, сумма)
- «Отметить выплаченной» (если статус = не выплачено) → модалка: сумма (пред-заполнена рассчитанной), заметка, кнопка «Подтвердить выплату»

**Расчёт зарплаты — логика:**

Кнопка «Пересчитать» — пересчитывает зарплаты по текущим настройкам:

- `percent`: `salary = revenue * percent_value / 100`
- `fixed`: `salary = fixed_amount` (не зависит от выручки)
- `mixed`:
  - Если `revenue <= monthly_norm`: `salary = fixed_amount`
  - Если `revenue > monthly_norm`: `salary = fixed_amount + (revenue - monthly_norm) * percent_value / 100`

## STEP 7 — Экспорт

### Excel (.xlsx)

Использовать `openpyxl` на бэкенде.

**P&L экспорт:** один лист «P&L», таблица с категориями доходов и расходов, итоги, маржа. Шапка с названием салона и периодом.

**Зарплаты экспорт:** один лист на каждого мастера — имя, период, список его записей (дата, услуга, сумма), расчёт зарплаты, итог.

**Касса экспорт:** список всех транзакций за период с итогами.

### PDF

Использовать `weasyprint` (если установлен) или `reportlab`.

**Расчётный лист зарплаты** — красиво оформленный PDF на каждого мастера: логотип салона, имя мастера, период, таблица услуг, расчёт, итоговая сумма к выплате.
